INSTALL ON IPHONE OR IPAD BEFORE PLAYING

Safari and Home Screen apps keep separate save data. Install first so crystals and Command Web progress stay in one place.

  1. Tap Safari's Share button.
  2. Choose Add to Home Screen.
  3. Open Rogue Maul from its new icon.

Requires iOS 15 or newer. On iOS 15/16, browser storage is best-effort; use the Command Web save backup controls.

Already played at this address? Safari keeps that older save separate from the installed app.

A backup-only recovery screen will open. Download the old save, return here, install Rogue Maul, and restore the file from Command Web. Gameplay remains disabled in recovery.
